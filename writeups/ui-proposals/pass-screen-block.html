What changes (and what doesn't)

  • One tile per order, not per station. Unlike the kitchen display, items are not split by location — the runner carries the whole order, so every line is on one tile.
  • An order only appears once every station has pressed READY. Nothing reaches this board half-made.
  • One full-width button per tile. Sized for a thumb on a busy pass — no menus, nothing to learn, no confirm step.
  • Order age is prominent. Oldest first, with a ticking age, because at the pass the oldest complete order is the one someone has been waiting on longest.
  • An incomplete order is flagged, not hidden (tile #44). An item whose product has no prep location can never be bumped, so the order would otherwise stall forever. It is offered with an amber warning and a “Toch afgegeven” button, so the runner decides knowingly.
  • Staff orders keep the same amber marker as the kitchen display, so the two screens read the same way.
  • Unchanged: the kitchen display and its bump. This is a second stage on top, not a redefinition — a bump still means “my station is done”.
  • Delivery is a page-editor block (passScreenBlock), no new route — your call. Labels shown in Dutch because kassa is nl-only; the block ships en/nl/fr.
Static mockup — the block does not exist yet, so there is nothing deployable to preview. Rendered offline; no JS, no external assets.
