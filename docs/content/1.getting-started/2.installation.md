Here's how to install and configure Nuxt Crouton in your [Nuxt](https://nuxt.com) 4 project.

::callout{icon="i-lucide-triangle-alert" color="red"}
**Nuxt 4 Required**: Nuxt Crouton requires **Nuxt 4** and **Nuxt UI 4**. It will not work with Nuxt 3 due to the `app/` directory structure convention used by layers. See [Troubleshooting - Layer Pages 404](/guides/troubleshooting#layer-pages-404-errors) if you encounter routing issues.
::

## Prerequisites

You'll need Node.js 18 or 20+, pnpm (recommended) or npm, Nuxt 4.x, and [Nuxt UI](https://ui.nuxt.com) 4.x.

## Install Nuxt Crouton

```bash
# Install the core layer (bundles auth, admin and i18n)
pnpm add @fyit/crouton-core

# Install generator (dev dependency)
pnpm add -D @fyit/crouton-cli
```

## Configure Nuxt

Add Nuxt Crouton to your `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [
    '@fyit/crouton-core',   // Core CRUD — bundles auth, admin and i18n

    // Optional features: install the package and extend it
    // (see Package Architecture for the full list)
    // '@fyit/crouton-editor',   // Rich text editing
    // '@fyit/crouton-assets',   // Asset management
    // '@fyit/crouton-ai',       // AI integration
    // '@fyit/crouton-email',    // Email templates
    // '@fyit/crouton-pages',    // CMS pages
  ],

  hub: { db: 'sqlite' },

  // Recommended: Enable hot reload for development
  vite: {
    server: {
      watch: {
        ignored: ['!**/node_modules/@fyit/**']
      }
    },
    optimizeDeps: {
      exclude: ['@fyit/crouton-core']
    }
  }
})
```

::callout{icon="i-lucide-box" color="blue"}
**Bundled in core:** `@fyit/crouton-core` extends `@fyit/crouton-auth` (authentication), `@fyit/crouton-admin` (super admin) and `@fyit/crouton-i18n` (translations), and registers `@nuxthub/core`, `@nuxt/ui`, `@vueuse/nuxt`, `@nuxt/image` and `@nuxtjs/seo` itself. Don't list any of these in your own `extends` or `modules` — they're already there.
::

## Configure Tailwind CSS

Nuxt Crouton layers use Tailwind CSS classes that need to be scanned by the Tailwind compiler. Due to how Tailwind CSS v4 works with Nuxt Layers, you need to add the `@source` directive to your app's CSS file to ensure layer components are properly styled.

::callout{icon="i-lucide-check-circle" color="green"}
**Automatic Setup**: The collection generator (`crouton-generate`) and installer (`crouton-install`) will **automatically** configure the `@source` directive for you! If you run either of these commands, you can skip manual configuration.
::

### Automatic Setup (Recommended)

When you run the generator or installer, it will:
1. Detect your existing CSS file (or create `app/assets/css/main.css`)
2. Add the required `@source` directive automatically
3. Update `nuxt.config.ts` if a new CSS file was created

```bash
# The generator sets up CSS automatically
npx crouton-generate <layer> <collection> --fields-file=./schema.json
```

### Manual Setup

If automatic setup fails or you prefer manual configuration, create or update your main CSS file (e.g., `app/assets/css/main.css`):

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

/* Scan Nuxt Crouton layers - REQUIRED for proper styling */
@source "../../../node_modules/@fyit/crouton-*/app/**/*.{vue,js,ts}";
```

::callout{icon="i-lucide-lightbulb" color="amber"}
The `@source` directive path is **relative to your CSS file location**. Adjust the `../` depth based on where your CSS file is located:
- If CSS is at `app/assets/css/main.css`: use `"../../../node_modules/..."`
- If CSS is at `app.css`: use `"../node_modules/..."`
::

::callout{icon="i-lucide-info"}
**Why is this needed?** Tailwind CSS v4 doesn't automatically scan external layers in `node_modules`. The `@source` directive explicitly tells Tailwind where to find classes used in layer components. Without this, hover states and dynamic classes won't work. [Learn more](https://github.com/nuxt/ui/issues/5104)
::

### For Multiple Layers

The wildcard pattern `@fyit/crouton-*/` automatically scans all installed Nuxt Crouton layers:
- `@fyit/crouton-core`
- `@fyit/crouton-i18n`
- `@fyit/crouton-editor`
- `@fyit/crouton-assets`

Alternatively, you can list each layer explicitly:

```css
@source "../../../node_modules/@fyit/crouton-core/app/**/*.{vue,js,ts}";
@source "../../../node_modules/@fyit/crouton-i18n/app/**/*.{vue,js,ts}";
@source "../../../node_modules/@fyit/crouton-editor/app/**/*.{vue,js,ts}";
```

## Verify Installation

Check that the generator is installed correctly:

```bash
npx crouton-generate --help
```

You should see:

```
Usage: crouton-generate <layer> <collection> [options]
```

## Pre-Generation Checklist

Before running the generator, ensure you've completed these steps:

::steps
### Install the package
```bash
pnpm add @fyit/crouton-core
pnpm add -D @fyit/crouton-cli
```

### Add to nuxt.config.ts
The generator checks that the core layer is extended:
```ts
extends: ['@fyit/crouton-core']
```

### Create your schema file(s)
Create JSON schema files defining your collection fields. See [Schema Format](/generation/schema-format).

### Run the generator
```bash
npx crouton-generate <layer> <collection> --fields-file=./schema.json
```
::

::callout{icon="i-lucide-triangle-alert" color="amber"}
**Common issue**: If you get a "Missing Required Dependencies" error even though the package is installed, make sure you've added `@fyit/crouton-core` to the `extends` array in `nuxt.config.ts`.
::
