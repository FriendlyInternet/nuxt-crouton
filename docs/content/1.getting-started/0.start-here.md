The exact commands to go from an empty folder to a running crouton app with a working CRUD page. These are the same commands the release clean-room check runs.

<!-- clean-room -->
```bash
npx @fyit/crouton-cli init my-app --out my-app
cd my-app
pnpm install
echo '[{"name":"name","type":"string"},{"name":"price","type":"number"}]' > products.json && npx crouton generate shop products --fields-file=products.json
pnpm dev
```

Then open the dev server URL and visit the new `products` collection.

::callout{icon="i-lucide-info" color="blue"}
**For maintainers:** the code block right after the clean-room HTML comment is parsed by `scripts/clean-room-commands.mjs`. The check runs one command per line, so edit the block here and nowhere else. The extractor fails if the block is missing, has more than five lines, or the comment appears twice.
::
