## The one naming rule

Every collection's components are named from its **layer** and **plural name**, in PascalCase:

| Component | Name | Example (layer `shop`, collection `products`) |
|-----------|------|-----------------------------------------------|
| Form | `<Layer><Plural>Form` | `ShopProductsForm` |
| List | `<Layer><Plural>List` | `ShopProductsList` |
| Detail (optional) | `<Layer><Plural>Detail` | `ShopProductsDetail` |

The collection key in your config (`shopProducts`) is the same name with a lower-case first letter. There is no
per-collection form setting or registration to maintain: the form loader works out the name from the
collection key and loads that component the first time it opens.

## Eject: replace a form or list in one file

To replace a form or list that a package (or the generator) provides:

1. Find the name: layer + plural collection name. For a package collection, the layer is its prefix
   (`bookings` + `locations` → `BookingsLocationsForm`); for your own collections it is the layer folder you generated into.
   The collection key shown in `app.config.ts` under `croutonCollections` is the same name with a lower-case first letter.
2. Create the file in your **app**: `app/components/BookingsLocationsForm.vue` (or `…List.vue`).
3. Done. A component in the app's `app/components` wins over the package's with the same name.

```vue [app/components/BookingsLocationsForm.vue]
<script setup lang="ts">
const props = defineProps<{ collection: string, action: string, activeItem?: any, loading?: string }>()
</script>

<template>
  <!-- your own form -->
</template>
```

To go back to the package version, delete the file.

::callout{type="warning"}
Generated collections keep their form as `_Form.vue` / `List.vue` inside the layer; those files are yours to edit directly. Ejecting is for
collections you do **not** own, such as those shipped by `@fyit/crouton-bookings` or `@fyit/crouton-sales`.
::
