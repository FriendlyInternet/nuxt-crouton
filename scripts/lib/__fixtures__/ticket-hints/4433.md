## Hypothesis
**We think that** video and `.vtt` should be uploadable by default (or with one documented setting), with a size limit that works on Cloudflare. **We'll know by** uploading a 100 MB video in the media library.

## 👤 What this is about
Default upload types are images, PDF and Office files, max 10 MB.

## ⚠️ Needs the owner's decision first
This changes a recorded security policy: `packages/crouton-core/server/utils/upload-types.ts` cites **#3132** ("No HTML, no video/audio"), and `tests/api/upload-image.test.ts` asserts `video/mp4` is refused with 400. Allowing video (and `.vtt`) uploads reverses it. The plan must ask the owner (yes/no) before any code; it is not a plan detail.

## 🧪 What the prototype did — assume it is wrong or unclean
A local, unpushed prototype (a four-language course site in `pocs/`) proved this need with quick spike code. Treat the following as a **sketch to challenge**, not an implementation to copy:

- The app overrode `runtimeConfig.public.croutonUpload` with a full copy of the default type list plus video/vtt and `maxSize: 256MB`.
- **Likely problems:** copying the default list; 256 MB is above Cloudflare request limits; large files may need direct-to-R2 (multipart/presigned) uploads.

## ❓ Answer these in the plan, before building
1. **Is this a good idea at all?** Does the need hold up, or is there a reason not to do it (cost, complexity, a better product answer)? Say so if it should be dropped or reshaped.
2. **Is this the crouton way?** Is there already a crouton-core or package component, composable, convention or config for this (or most of it)? Extend that instead of adding a parallel one.
3. **Is this the Nuxt way?** Nuxt / Nitro / @nuxtjs/i18n / unhead / NuxtHub built-ins before custom code.
4. **Right Nuxt UI 4 components?** Use the v4 components and patterns — no raw-HTML re-implementations.
5. **DRY?** Does it duplicate logic that exists elsewhere (another package, the page editor, the generator)?
6. **Simpler or smarter?** If you see a better way than the prototype or this ticket, propose it — the ticket describes the *need*, not the solution.

## ✅ Done when

## 🧪 How to test
1. Upload a ~100 MB mp4 and a .vtt in the media library on a Cloudflare deploy.
2. Both appear and play/load on a page.
