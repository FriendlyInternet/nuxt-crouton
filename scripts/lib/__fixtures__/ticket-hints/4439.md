## Hypothesis
**We think that** the generator should produce working code for sortable, translated collections with references. **We'll know by** generating such a collection and using it without edits.

## 👤 What this is about
**Narrowed after review to the sortable bugs only.** Found in a prototype:
- Regenerating a collection as `sortable` added the reorder endpoint but **didn't rewrite the queries file** it imports (app crashed).
- The endpoint sends `{ id, order }` while the sortable query reads the order field's name (`position`) — sorting would save nothing.
- The generated client config doesn't say the collection is sortable.

Split out: #4446 (dropdown default), #4447 (sibling references), #4448 (translation keys dropped).
